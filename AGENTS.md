# Project practices

Preserve original benchmark, model, data, accuracy sampling and official fixed serve arguments. Keep raw results immutable; label short diagnostics separately from official four-round results. Report discarded warmup rounds and failed requests honestly. Never claim unmeasured optimization gains or frequency hypotheses as causes. Keep credentials, model weights and compiler caches outside this repository. Respect each user-confirmed reservation and stop project workloads before its cutoff. Do not send external messages without user authorization.
