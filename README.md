# FlagOS MiniCPM throughput project

MiniCPM5-2B 在 FlagOS 天数 BI-V150 上的基线复现、诊断与后续优化项目。当前尚未实现原创优化，也尚未达到官方性能参考的 1% 容差。

## 已完成的正式实测（2026-10-29 日间）

| 负载 | 实测 total tokens/s | 天数参考 | 实测 Mean TTFT (ms) | 参考 TTFT (ms) |
|---|---:|---:|---:|---:|
| 4K / 1024 output | 1874.1967 | 2028.01 | 12333.07 | 11573.53 |
| 16K / 1024 output | 862.0300 | 915.15 | 636477.0433 | 599262.03 |

两组各完整四轮，按原版脚本丢首轮、平均后三轮；4K 每轮256/256、16K 每轮128/128成功，token总量完整。精度本次105题全部正常完成，102题正确（97.14%），105个stop。精度通过，性能未通过。另一组官方参考是沐曦硬件，不用于本机比较。
